# Roadmap

Plans may change as Phantom Shell develops.

## English

- [ ] Finish making the essential shell components independent of the Caelestia packages.
- [ ] Complete integration of the bar, installer and remaining Waybar-related components.
- [ ] Continue porting settings for the top bar and verify floating mode in a real session.
- [ ] Expand Hyprland settings for mouse, touchpad, keyboard layouts, monitors and VRR.
- [x] Give the dashboard About section Phantom branding and its own GitHub link.
- [x] Add an Update section with version information and release history.
- [ ] Test the complete shell in a virtual machine, including clean installation, multiple monitors, tray, popouts, Wi-Fi and fullscreen behavior.
- [ ] Finalize documentation, screenshots, video, licensing and attribution before publication.

## Русский

- [ ] Завершить работу над независимостью основных компонентов shell от пакетов Caelestia.
- [ ] Завершить интеграцию бара, установщика и оставшихся компонентов, связанных с Waybar.
- [ ] Продолжить перенос настроек верхнего бара и проверить плавающий режим в реальной сессии.
- [ ] Расширить настройки Hyprland: мышь, тачпад, раскладки клавиатуры, мониторы и VRR.
- [x] Оформить раздел About в стиле Phantom и добавить ссылку на собственный GitHub.
- [x] Добавить раздел Update с информацией о версиях и историей релизов.
- [ ] Проверить полный shell в виртуальной машине: чистую установку, несколько мониторов, трей, попоуты, Wi-Fi и полноэкранный режим.
- [ ] Завершить документацию, скриншоты, видео, лицензирование и указание авторства перед публикацией.
